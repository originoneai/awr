# Markdown work ledgers

Use `markdown-ledger-v1` for existing tables and checklists. Reading preserves source
status and never infers engineering verification. Writing supports explicit stable IDs
and finite single-line forms; unsupported structures remain readable where possible.
See the [host contract](../../docs/dev/reference/host-contract.md#markdown-ledger-writes)
for field preservation, metadata, creation, domain actions and recovery limits.
