# AWR Team 1.0.0-beta.1

AWR Team Beta provides a shared Team MCP service and the Observer workspace for
collaborative project delivery trials. Agents connect with scoped member
credentials to read, claim, execute and report work. Observer shows project goals,
work, activity and delivery evidence.

## Included components

- The native Team Server with PostgreSQL TLS support.
- The Observer production application and its Node.js dependencies.
- A pinned Node.js 24 LTS runtime for the Linux x64 deployment.
- A release manifest, file checksums and dependency license notices.

The Team bundle version is **1.0.0-beta.1**. Its server component uses the
**0.8.1** source version, Observer uses **0.1.0**, and the Node.js runtime is
**24.22.3**. The manifest records the exact source SHA, component versions,
platform and artifact digests.

## Deployment and access

The Beta entry point is <https://beta.awr.originoneai.com/>. Members connect an
MCP-capable Agent using their project's HTTPS MCP URL and a scoped personal
credential. Project work follows the Agent workflow, and Observer provides the
shared observation workspace.

The selected source requires Team PostgreSQL schema **60**. Before upgrading an
existing deployment, capture a consistent database, source, configuration and
program backup. Rehearse migration and restore on an isolated database copy,
verify authenticated access and the built Observer assets, then replace the
selected services with the verified artifacts. Retain the matching rollback
release and preserve work written after the upgrade.
See the [Team deployment guide](../reference/team-deploy-pack.md).

## Trial verification

Use this Beta to run complete collaborative delivery scenarios with the chosen
Agents. Record task assignment or claims, implementation, progress feedback,
independent review and final delivery against the active acceptance contract.
The release record identifies the deployment checks performed and the business
scenarios still awaiting execution.
